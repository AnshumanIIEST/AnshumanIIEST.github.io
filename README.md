# Anshuman Vikram — Research Portfolio

A responsive, single-page academic and research portfolio.

## Preview locally
Open `index.html` in a browser. The stock photographs and Google Fonts require an internet connection.

## Publish with GitHub Pages
1. Create a new public GitHub repository (for example, `anshumanvikram.github.io`).
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. After GitHub finishes deploying, your site will be available at `https://YOUR-USERNAME.github.io/`.

## Replace stock photographs
Search in `index.html` for `images.unsplash.com`. Replace each image URL with your own image path, for example:
`<img src="images/my-robot.jpg" alt="My robotics project">`

For best results, create an `images` folder in the repository and upload your photographs there.

## Before publishing
- Replace `YOUR_EMAIL@example.com` with the email address you want to make public.
- Replace LinkedIn, GitHub and Google Scholar links with your own profile URLs.
- Review the biography, project descriptions and education details.
- Consider adding a current CV PDF if you want visitors to download it.
- The current photographs are illustrative stock images, not photographs of your own laboratory work.


## User-supplied laboratory photographs
The `images/` folder contains the photographs supplied for this portfolio. `main.jpg` is used in the hero area. The gallery and engineering cards use the Smart Health IoT Lab, KUKA and MICO robots, electro-pneumatic setup, industrial automation model, PLC training kits, sensor trainer and PLC control cabinet photographs.
